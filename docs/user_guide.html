URL Shortener

Developer User Guide · Getting started for co-developers · Repo: github.com/Atiba2125/URL_Shortner

1. What this project is

A URL shortener. A user pastes a long URL (for example a Google search results link) into a web page; the backend validates it, generates a short code such as aB3xY9, stores the mapping in a database, and returns a short link like https://xyz.com/aB3xY9. Opening the short link redirects to the original URL and counts the click.

Current status. Done: shortener core (API, validation, short codes), PostgreSQL support, click counting with a stats API, the frontend, an admin panel (login, search, edit, delete), a CLI tool, rate limiting, friendly error pages, 37 automated tests, and deploy/backup/hardening templates (not yet run on a real VPS). Not built: the client's "Google proxy / masking" mode (custom domain in the address bar while the VPS renders Google's results page, with Google cookies and Search Console tracking). It is deliberately left out — see section 12. Short links do a normal 302 redirect, so the address bar shows the destination site.

3. Prerequisites

  • Python 3.10 or newer (python --version)
  • Git
  • Optional: PostgreSQL 14+ (only if you want to test against Postgres instead of SQLite)

4. Quick start (local)

git clone https://github.com/Atiba2125/URL_Shortner.git
cd URL_Shortner
python -m venv venv

Activate the virtual environment:

# Windows PowerShell
venv\Scripts\Activate.ps1
# Linux / macOS
source venv/bin/activate

Install dependencies and start the server:

pip install -r requirements.txt
uvicorn app.main:app --reload

Open http://localhost:8000. With no .env file the app creates a local SQLite file (shortener.db) automatically — nothing else to set up.

Windows tip: if PowerShell blocks Activate.ps1, skip activation and run venv\Scripts\python -m uvicorn app.main:app --reload.

5. Using the app

  1. Open http://localhost:8000.
  2. Paste a URL and click Shorten.
  3. Click Copy to copy the short link.
  4. Open the short link — it redirects (HTTP 302) to the original URL and increments its click counter.
  5. The "Recent links" list under the form shows each link's clicks (use Refresh clicks).

Interactive API docs: http://localhost:8000/api/docs

6. API reference

EndpointDescription
POST /api/shortenBody {"url": "https://..."}. Returns {code, short_url, original_url}. 422 if the URL is invalid; 429 if the per-IP rate limit is exceeded.
GET /api/links/{code}Stats: {code, short_url, original_url, click_count, created_at}; 404 if unknown.
GET /{code}302 redirect to the original URL and adds 1 to click_count; 404 if unknown. HEAD requests (link previews, health checks) are not counted.
GET /healthHealth check; also verifies the database connection.
curl -X POST http://localhost:8000/api/shorten -H "Content-Type: application/json" \
  -d "{\"url\": \"https://www.google.com/search?q=pizza\"}"

URL validation rules

  • Only http:// and https://; maximum 2048 characters; no spaces or control characters.
  • Rejected: javascript:, ftp:, localhost, private/local IP addresses, URLs with embedded user:password@.
  • Optional host allow-list through ALLOWED_HOSTS (e.g. www.google.com,google.com).

7. Admin panel and CLI

Admin panel: set ADMIN_USERNAME and ADMIN_PASSWORD in .env (an empty password disables the panel and returns 503), restart the server, then open http://localhost:8000/admin and sign in with the browser's login box. Features: link count and total clicks, search by code or URL, pagination, Copy, Edit (change a link's destination URL) and Delete. Use a long random password and HTTPS in production, because HTTP Basic login sends the password with every request.

CLI (works on the server without logging in):

python -m app.cli create "https://www.google.com/search?q=pizza"
python -m app.cli list --limit 20
python -m app.cli stats CODE
python -m app.cli edit CODE "https://new-destination"
python -m app.cli delete CODE

Rate limit: RATE_LIMIT_PER_MINUTE (default 30) limits link creation per IP; extra requests get HTTP 429 with a Retry-After header. Nginx adds its own limit in production. Errors: unknown short links show a friendly 404 page in browsers and JSON to API clients.

Using PostgreSQL locally

Windows: install PostgreSQL from postgresql.org (remember the postgres password; you can skip Stack Builder), open SQL Shell (psql), press Enter at each prompt, enter the password, then run CREATE DATABASE shortener;. The driver (psycopg[binary]) is in requirements.txt.

Linux:

sudo -u postgres createuser shortener -P
sudo -u postgres createdb -O shortener shortener

Then in .env set DATABASE_URL=postgresql+psycopg://postgres:YOUR_PASSWORD@localhost:5432/shortener and BASE_URL=http://localhost:8000, and restart uvicorn. Tables are created automatically on startup; introduce Alembic migrations if the schema grows. To view data use pgAdmin (Servers → PostgreSQL → Databases → shortener → Schemas → public → Tables → links → right-click → View/Edit Data → All Rows), or DB Browser for SQLite for the local shortener.db.

To copy links from the local SQLite file into PostgreSQL (safe to run twice): python -m scripts.migrate_sqlite_to_db shortener.db

10. Running tests

pytest

Tests always use a temporary SQLite database (test_shortener.db, git-ignored) and never touch PostgreSQL. They cover shortening, redirects, click counting, admin login/search/edit/delete, the CLI, rate limiting (429), unicode and very long URLs, malformed requests, 404 pages and more. Add a test with every change.

11. Deploying to production (Ubuntu VPS)

  1. Install packages: sudo apt install nginx postgresql python3-venv certbot python3-certbot-nginx
  2. Create the Postgres user and database (see section 8).
  3. Copy the project to /opt/shortener, create a venv, pip install -r requirements.txt, create .env with production values: real BASE_URL (https), a strong ADMIN_PASSWORD, PostgreSQL DATABASE_URL (chmod 600 .env).
  4. Install deploy/shortener.service to /etc/systemd/system/, then sudo systemctl enable --now shortener.
  5. Install deploy/nginx-xyz.conf into Nginx (change xyz.com to the real domain), point the DNS A record at the VPS, then run sudo certbot --nginx -d yourdomain.com.
  6. Security: review and run deploy/harden.sh (firewall allowing only SSH/HTTP/HTTPS, fail2ban, automatic security updates, PostgreSQL on localhost only).
  7. Backups: install deploy/backup.sh as a nightly cron job (instructions and restore command are at the top of the file; 14 days are kept). Logs are in /var/log/nginx/ and journalctl -u shortener.

The Nginx template includes an HTTPS redirect, security headers, a request-size limit and a rate limit on /api/shorten.

12. The Google proxy / masking requirement (not built)

The client briefs ask that opening a short link keeps the custom domain in the address bar while the VPS renders Google's results page through a reverse proxy (with asset/redirect rewriting, Google cookies/scripts and Search Console tracking). This is intentionally not implemented. Everything else in the scope — shortener, CLI, admin panel, rate limiting, error handling, tests, VPS/Nginx/SSL deployment — is implemented. Reasons:

  • Unreliable: Google blocks proxies (bot detection, CAPTCHAs, redirect links), so it cannot be guaranteed to work.
  • Security and impersonation: it shows Google's page under another domain, and passing Google cookies through this server would expose users' Google sessions to the server operator.
  • Tracking: Search Console attribution cannot be guaranteed, and making proxied clicks count as organic search clicks would be click manipulation against Google's policies.

Do not add it unless the client states a legitimate purpose and confirms it is permitted under Google's terms. What the app does provide: branded short links that redirect to the original page, per-link click counts, an admin panel and a CLI.

13. Team workflow & conventions

  • Branch from main (git checkout -b feature/short-name); open a pull request; get a review before merging.
  • Run pytest before every push; add tests for new behaviour.
  • Never commit secrets (.env), the venv/ folder or *.db files.
  • Keep the catch-all route GET /{code} last in app/main.py; new routes go above it, and new reserved paths must be added to RESERVED in app/codes.py.

14. Troubleshooting

ProblemFix
Activate.ps1 blocked on WindowsRun venv\Scripts\python -m uvicorn app.main:app --reload, or Set-ExecutionPolicy -Scope CurrentUser RemoteSigned.
ModuleNotFoundErrorThe venv is not active or dependencies are not installed: activate it and run pip install -r requirements.txt.
Port 8000 already in useRun uvicorn with --port 8001.
Cannot connect to PostgreSQLCheck DATABASE_URL, that the service is running, and that the user and password are correct.
Short links show localhost or the wrong domainSet BASE_URL in .env.
/admin returns 503ADMIN_PASSWORD is empty in .env; set it and restart.
/admin keeps asking for loginWrong username or password; check ADMIN_USERNAME / ADMIN_PASSWORD.
HTTP 429 when creating linksRate limit reached; wait a minute or raise RATE_LIMIT_PER_MINUTE.
